# StreamerFlow Project Rules

## Tech Stack
- Laravel 12
- PHP 8.3+
- Tailwind CSS
- Vite
- MySQL

## Coding Standards
- Follow SOLID principles
- Keep controllers thin
- Use service classes for business logic
- Prefer Eloquent relationships over raw SQL
- Use Laravel naming conventions
- Use Form Requests for validation

## Frontend Rules
- Use Tailwind utility classes
- Avoid inline CSS
- Keep Blade templates modular

## Backend Rules
- Do not modify .env automatically
- Ask before changing database schema
- Prefer queues for heavy operations
- Use caching where appropriate

## Git Rules
- Never force push
- Never delete migrations without asking
- Explain risky commands before running them

## AI Assistant Behavior
- Explain changes before editing files
- Prefer minimal safe edits
- Ask before large refactors
- Optimize for maintainability

## Project Goal
StreamerFlow is a scalable Laravel streaming and creator platform focused on performance and maintainable architecture.
